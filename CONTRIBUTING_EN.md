# Contributing to AI Berkshire

Thank you for your interest in AI Berkshire! We welcome contributions in all forms.

## How to Contribute

### 1. Report Contribution

If you have completed an investment research report using the AI Berkshire framework, we would be happy to receive your PR.

**Requirements:**
- The report must follow the Four Masters framework (Buffett, Munger, Tan Yongping, Li Lu)
- Include complete business model analysis
- Include financial valuation analysis
- Include competition analysis
- Include risk assessment

**Format:**
Submit following the `reports/{company_name}/` folder structure

### 2. Skills/Prompts Contribution

If you have improved or created a new Skill, you can submit a PR.

**Requirements:**
- Follow the existing Skill format
- Provide complete documentation
- Include usage examples

### 3. Bug Report

Found a problem? Submit an Issue.

**Please include:**
- Bug description
- Steps to reproduce
- Expected result vs actual result

### 4. Discussions and Suggestions

Have an idea? Open a Discussion.

## Code Style

- Python: PEP 8
- Markdown: GitHub Flavored Markdown
- Comments in Chinese, code in English

## Before Submitting a PR

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit your changes: `git commit -m "description of what you changed"`
4. Push to the branch: `git push origin feature/your-feature`
5. Create a Pull Request
