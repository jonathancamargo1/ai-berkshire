## Passo 1: Construção e Validação da Cadeia de Lógica de Investimento

### 1.1 Desenhar a cadeia de lógica

Usar setas para expressar relação causal de 'tendência de fundo' para 'alvo beneficiado', exemplo:
```
Tendência de Fundo A
    → Causa Demanda B
        → Cria Gargalo/Necessidade C
            → Beneficia Cadeia de Suprimentos D
```
