# Contribuindo para AI Berkshire

Obrigado pelo interesse em AI Berkshire! Aceitamos contribuições de todas as formas.

## Como Contribuir

### 1. Contribuição de Relatórios

Se você completou um relatório de pesquisa de investimento usando o framework AI Berkshire, gostaríamos de receber seu PR.

**Requisitos:**
- O relatório deve seguir o framework dos 4 Mestres (Buffett, Munger, Tan Yongping, Li Lu)
- Incluir análise completa do modelo de negócio
- Incluir análise de avaliação financeira
- Incluir análise de competição
- Incluir avaliação de riscos

**Formato:**
Envie seguindo a estrutura da pasta `reports/{nome_da_empresa}/`

### 2. Contribuição de Skills/Prompts

Se você melhorou ou criou um novo Skill, pode enviar um PR.

**Requisitos:**
- Seguir o formato existente de Skills
- Fornecer documentação completa
- Incluir exemplos de uso

### 3. Relatório de Bugs

Encontrou um problema? Envie uma Issue.

**Por favor inclua:**
- Descrição do bug
- Passos para reproduzir
- Resultado esperado vs resultado atual

### 4. Discussões e Sugestões

Tem uma ideia? Abra uma Discussion.

## Estilo de Código

- Python: PEP 8
- Markdown: GitHub Flavored Markdown
- Comentários em chinês, código em inglês

## Antes de Enviar um PR

1. Faça fork do repositório
2. Crie uma branch de feature: `git checkout -b feature/your-feature`
3. Envie suas alterações: `git commit -m "descrição do que você alterou"`
4. Envie para a branch: `git push origin feature/your-feature`
5. Crie um Pull Request
