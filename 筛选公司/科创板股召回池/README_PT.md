## Descobertas Principais

1. **Equipamento de Semicondutores é a Melhor Pista** — 7 empresas aprovadas; modelo "vendedor de pás" prova ser mais sólido após seleção de empresas pobres
2. **Margem Bruta Alta é Comum em Boas Empresas** — Empresas aprovadas margem bruta mediana ~45%, vs ~25% mediana para todas as 100 empresas
3. **Qualidade de Lucratividade Geral da Placa STAR Preocupante** — 56% das empresas eliminadas por perdas; "crescimento de tecnologia" ≠ "bom negócio"
4. **Empresas de Limite Valem Rastreamento de Longo Prazo** — 18 empresas como Haiguang, Tujing, China Railway Signal precisam de mais validação de dados financeiros
